# Ultimate Beginner's Guide to EVE Online — Glossary

> **Glossary version:** 1.0  
> **Created:** August 18, 2026  
> **Status:** Governing project source  
> **Purpose:** Provide one canonical beginner-readable definition for recurring EVE terminology.

---

## Usage Rules

- Define an EVE-specific term in plain language at first use and link here when useful.
- Use the definition below consistently rather than creating a competing explanation.
- A section may add context appropriate to its subject without changing the core meaning.
- Do not place volatile statistics, bonuses, prices, or policy limits in the glossary.
- Research and record any material definition change in the guide change log.

## Accounts, Characters, and Training

| Term | Governing beginner definition |
|---|---|
| Account | The login and subscription container that holds character slots and has a clone state. |
| Account architecture | The planned placement of roles and characters across accounts based on training, simultaneous-login needs, security, cost, and operations. |
| Alpha account | An account without active Omega game time and therefore subject to current Alpha restrictions. |
| Alt | An additional character used for a supporting, specialized, independent, or identity-separated role. |
| Character | One capsuleer identity occupying a character slot on an account. |
| Client | One running instance of the EVE application connected to one logged-in account. |
| Clone state | The account's current Alpha or Omega access state. |
| Main | The character a player treats as their primary identity or progression focus; not necessarily the most skilled character for every role. |
| MCT | Multiple Character Training, which activates an additional simultaneous skill-training queue on the same account for a defined period; it does not allow same-account characters to log in together. |
| Multiboxing | One player manually and independently operating multiple EVE clients at the same time. |
| Omega account | An account with active Omega game time and access to Omega capabilities supported by the character's trained skills. |
| Skillbook | An item or direct purchase that makes a skill available for a character to train. |
| Skill Point (SP) | A unit of character training progress assigned to skills. |
| Skill queue | The ordered list of skills a character will train over real time. |
| Support skills | Skills that improve fitting, capacitor, navigation, tank, targeting, weapons, or other capabilities across several ships. |
| Unallocated SP | Skill Points the player can apply directly to eligible skills instead of waiting for normal training. |

## Ships, Fitting, and Flight

| Term | Governing beginner definition |
|---|---|
| Align time | The time a ship needs to reach the direction and speed required to enter warp. |
| Capacitor | A ship's rechargeable energy reserve used by many modules and weapons. |
| Calibration | The fitting resource consumed by rigs. |
| CPU | One of the two main fitting resources consumed by installed modules. |
| Drone bandwidth | The limit controlling which combination of drones a ship can have active. |
| Drone bay | Storage aboard a ship for assembled drones. |
| Falloff | The range beyond a turret's optimal range where hit chance and effective damage progressively decline. |
| Fit | The complete combination of modules, rigs, charges, drones, and other equipment prepared for a ship and purpose. |
| Fitting simulation | A client mode used to test a fit without first buying or installing its parts. |
| Grid | The local area of space in which ships and objects can directly see and interact with one another. |
| Hull | Either a ship type itself or, in combat context, the final structural health layer beneath shields and armor. |
| Module | Equipment installed in a ship slot to provide weapons, defenses, propulsion, electronic effects, or utility. |
| Optimal range | The distance within which a turret avoids range-based accuracy loss, before other factors such as tracking are considered. |
| Powergrid | One of the two main fitting resources consumed by installed modules. |
| Propulsion module | An afterburner or microwarpdrive used to increase a ship's speed. |
| Rig | A fitted ship modification that uses calibration and is normally destroyed if removed. |
| Signature radius | A measure of how large a target appears to weapons and sensors; larger signatures are generally easier to hit or damage effectively. |
| Tank | The defenses used to absorb, resist, avoid, or repair incoming damage. |
| Transversal | Sideways angular movement between ships that affects how well turrets can track. |

## Space, Travel, and Survival

| Term | Governing beginner definition |
|---|---|
| Asset safety | A structure-related system that can move eligible personal assets when access to them is lost, subject to current rules, delays, and fees. |
| Bookmark | A saved location that a character can use for navigation or tactical positioning. |
| Bubble | A warp-disruption field used in space where the mechanic is permitted. |
| CONCORD | The NPC enforcement organization that responds to criminal aggression in ordinary high-security space; it punishes qualifying attacks but does not guarantee prevention. |
| Directional scanner (d-scan) | A shipboard scanner used to look for many nearby objects within a chosen range and angle without launching probes. |
| Exordium | The protected starter region where newly created characters begin the current new-player journey. |
| Highsec | High-security empire space governed by Crimewatch and CONCORD mechanics; it is safer than many regions but not generally free from player attack. |
| Lowsec | Low-security empire space with fewer restrictions on player combat and no CONCORD response. |
| Nullsec | Space with a security status at or below zero and broad access to player combat mechanics, including warp disruption bubbles where permitted. |
| Pochven | A group of Triglavian-controlled systems with distinctive travel, standings, combat, and access rules. |
| Safe bookmark | A bookmark away from common celestial objects and travel lines, used to reduce exposure while in space; it does not create guaranteed safety. |
| Session-change timer | A short restriction after certain actions that prevents another session-changing action until the timer ends. |
| Stargate | A fixed structure that moves ships between connected solar systems. |
| Tether | Conditional protection and service access provided near eligible friendly structures under current mechanics. |
| Wormhole | A temporary connection between systems whose destination, lifetime, and mass capacity must be evaluated. |

## Combat, Fleets, and Organizations

| Term | Governing beginner definition |
|---|---|
| Aggression timer | A visible timer created by certain actions that can restrict docking, tethering, jumping, logging off safely, or other behavior. |
| Alliance | A formal organization made up of player corporations. |
| Coalition | An informal or tool-supported grouping of alliances and corporations; it is not a separate in-game organization type. |
| Corporation | An NPC- or player-run organization to which a character belongs. |
| Doctrine | A standardized set of ships, fits, skills, and operating expectations selected by a group for a purpose. |
| EWAR | Electronic warfare: modules or effects that interfere with another ship's sensors, range, tracking, propulsion, capacitor, or combat effectiveness. |
| Fleet | The in-game organization used to group characters for leadership, broadcasts, bonuses, movement, and coordinated activity. |
| Fleet Commander (FC) | The person directing a fleet's actions. |
| Logistics | Depending on context, either moving supplies and ships or using remote-repair ships to keep fleet members alive. Clarify the intended meaning when first used. |
| Point | Common shorthand for a warp disruptor or for having a target prevented from warping. |
| Scram | Common shorthand for a warp scrambler, which prevents warp and disables some propulsion-related functions under current mechanics. |
| Tackle | Ships, modules, or actions used to prevent a target from escaping. |

## Economy, Industry, and Resources

| Term | Governing beginner definition |
|---|---|
| Blueprint Copy (BPC) | A limited-run copy of a blueprint used for manufacturing or invention and not researchable like an original. |
| Blueprint Original (BPO) | A reusable original blueprint that can normally be researched and copied. |
| Broker fee | A fee associated with creating or modifying eligible market orders. |
| Buy order | A market offer to purchase an item under stated price, quantity, location, and range conditions. |
| Contract | An in-game agreement used for item exchange, courier work, auctions, and other supported transactions. |
| Industry job | A timed activity installed to manufacture, research, copy, invent, or react materials and blueprints. |
| ISK | InterStellar Kredits, the principal in-game currency. |
| ISK per attention hour | Economic output divided by the time during which the activity actually demands the player's attention. |
| Liquidity | How readily an item can be sold near its expected price without excessive time or price reduction. |
| Opportunity cost | The value of the best alternative use of time, capital, characters, or assets that a choice displaces. |
| Planetary Industry (PI) | The extraction, processing, and transport of planetary resources through colonies managed by characters. |
| PLEX | An in-game item with account-service and store uses that can also be traded for ISK through authorized systems. |
| Reprocessing | Converting eligible items or resources into materials, subject to skills, facility, taxes, and other modifiers. |
| Sell order | A market offer listing an item for buyers at a stated price and location. |
| Standing | A numerical relationship between a character and an NPC, corporation, faction, or other entity that can affect access and costs. |

## Exploration and Interfaces

| Term | Governing beginner definition |
|---|---|
| Cosmic anomaly | A site that generally appears in the probe scanner without first resolving it with scan probes. |
| Cosmic signature | A site or wormhole that normally must be located precisely with scan probes before warping to it. |
| ESI | EVE Swagger Interface, CCP's official API through which approved applications can request authorized game data. |
| Overview | The configurable interface that lists selected nearby objects on the current grid. |
| Probe scanner | The interface used to view anomalies and signatures and to control scan probes. |
| Scan probes | Deployable probes used through the probe scanner to locate cosmic signatures or, with the appropriate type and equipment, ships and other objects. |
| SSO | Single Sign-On, CCP's official authorization system for signing into approved third-party applications without giving those applications the account password. |

## Rules and Security

| Term | Governing beginner definition |
|---|---|
| Account sharing | Allowing another person to access or play an account; prohibited under EVE's account rules. |
| Botting | Using software or automation to perform gameplay without the independent manual control required of a player. |
| ESI scope | A specific category of account or character data that a third-party application requests permission to access. |
| Input broadcasting | Duplicating one input across multiple clients; prohibited and never recommended by this guide. |
| Real-money trading (RMT) | Buying or selling in-game currency, assets, characters, or services through unauthorized real-money channels. |
| Two-factor authentication (2FA) | A security method requiring an additional authenticator or verification factor beyond the password. |
